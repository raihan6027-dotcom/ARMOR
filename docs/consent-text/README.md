# Teks persetujuan lapis 1

Teks yang disetujui pengguna sebelum ARMOR memproses wajah atau suaranya. Setiap teks punya versi. Aplikasi menampilkan teks versi terbaru, dan backend menyimpan versi yang disetujui beserta waktunya (`biometric_consents`). Jika teks diubah, buat file versi baru (misalnya `face-v2.md`), naikkan `CONSENT_TEXT_FACE` di konfigurasi, dan jangan ubah file versi lama.

| Media | Versi berlaku | File |
| --- | --- | --- |
| Wajah | `face-v1` | [face-v1.md](face-v1.md) |
| Suara | `voice-v1` | [voice-v1.md](voice-v1.md) |
