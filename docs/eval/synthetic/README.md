# docs/eval/synthetic/: uji jalan dengan data SINTETIS

Semua file di folder ini dibuat dari data SINTETIS (vektor acak, bukan wajah atau suara orang) hanya untuk memastikan skrip evaluasi berjalan. Angkanya **bukan hasil evaluasi**: jangan dikutip di proposal, jangan disalin ke `docs/eval/RINGKASAN.md`, dan jangan dipakai sebagai ambang konfigurasi.
